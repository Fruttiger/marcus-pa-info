Privacy policy

This policy describes Marcus PA Mail Mirror, a personal application operated by Marcus Fruttiger for his own use, and this public information website.

Setup status: checks so far have used mailbox-account metadata, not message content. No ongoing Gmail reader, mirror import or automatic cleanup is active. The read-only feature described below will run only after authorisation and local setup are complete.

Data access and purpose

The application requests Gmail read-only access (gmail.readonly) to verify the authorised account and support personal email task management. This permission can technically read messages and attachments throughout the authorised mailbox; labels are not an access boundary.

When enabled, the reader is intended to process selected message headers, sender and recipient information, dates, subjects, bodies, labels and message identifiers to identify actions, deadlines, waiting items and follow-ups. Attachment downloading and analysis are not enabled. Only the owner's dedicated, explicitly authorised mailbox is in scope.

The reader does not send email, alter messages or delete them. Future mirror import and cleanup features require separately approved permissions and an updated description before activation.

Storage and protection

Gmail messages remain hosted by Google. The planned reader processes selected data on the owner's computer. Useful task records, summaries, source references and processing metadata may be retained in the local PA; this website and its public repository do not receive any of that data.

Durable authorisation keeps the refresh token encrypted in owner-restricted local storage, with the encryption key held separately in macOS Keychain. Access tokens are kept in memory and are not saved to disk. The application's client configuration is kept in a private, owner-restricted local file. Secrets are not put in public source code or ordinary diagnostic logs. Protection of the owner's computer and account remains essential.

Use, sharing and AI processing

Google user data and derived records are used only for the owner's email productivity features. They are not sold, used for advertising, provided to data brokers, used for credit decisions, or used to train general-purpose AI models.

No external AI processor has been selected or enabled for this Gmail integration. Before any selected email content is sent to an external processor, the recipient, purpose and data involved must be disclosed and explicitly approved, with this policy updated as needed.

Other people are not given access to message content unless the owner expressly agrees to the specific access, or access is necessary for security or compliance with law. Any permitted transfer must remain within Google's applicable Limited Use requirements.

Marcus PA Mail Mirror's use and transfer of information received from Google APIs will comply with the Google API Services User Data Policy, including its Limited Use requirements.

Retention and deletion

No Gmail message content has been retained by this integration during setup. The proposed mirror cleanup is not active. Its intended 90-day window is an eligibility rule for moving processed mirror copies to Trash, not a guarantee of permanent deletion on day 90. New imports, unfinished processing and recovery holds would postpone cleanup; Gmail's own Trash retention also applies. Original source mail must not be deleted by mirror cleanup.

Local task records and source references have a separate purpose and are not automatically deleted when a mirror copy expires. The owner controls their review and deletion. Before collection is enabled, retention and recovery procedures for local data, logs and backups must be established; no automatic deletion interval is currently promised for them.

Withdrawing access

The owner can stop the local application and remove its connection in Google Account connections. Revoking access prevents further authorised API access but does not automatically erase existing Gmail messages or previously retained local records. Those must be reviewed and deleted separately, including applicable backups.

This information website

This site has no sign-in, forms, analytics scripts, advertising or mailbox connection. It sets no application cookies or browser-storage entries. GitHub Pages hosts the site and may retain visitor IP addresses and request information for security and operation under the GitHub Privacy Statement. Following an external link is subject to that service's own privacy practices.

Contact and changes

Questions about the application or this policy can be raised with its operator through the public information repository. Do not post email content, passwords, tokens or personal details there; request a suitable private contact route instead.

This page will be updated before material changes to data access, use or sharing. Newly requested permissions or uses require the owner's informed approval; publishing a policy update alone does not grant access.
