Personal application · App information

A private assistant for email follow-ups.

Marcus PA Mail Mirror is a single-user application operated by Marcus Fruttiger. Its purpose is to help its owner identify actions, deadlines and follow-ups in email selected for a dedicated Gmail mailbox.

Currently in setup. The Gmail connection is being prepared. Mailbox collection, mirroring and automatic cleanup are not active. This information page is not an email interface or a sign-in page.

Why Google access is requested

The read-only component uses the Gmail API to confirm the authorised mailbox and, once enabled, read selected messages for the owner's personal task management. Gmail read-only permission applies to the authorised mailbox, not just a label or folder.

The reader cannot send messages, change messages or delete mail. Any future import or cleanup component needs separate permissions and approval before it is enabled.

Where the assistant runs

The application is designed to run on the owner's computer. This public website hosts only application and privacy information. It has no connection to the mailbox, local PA database or OAuth credentials.

The planned mirror will copy only approved source mail into a dedicated Gmail account while leaving the original mailbox authoritative. The planned 90-day cleanup policy is not yet enabled.

Privacy and control

Read the privacy policy for the data involved, its intended use, storage, retention and how access can be withdrawn. This is a personal application, not a public email service or an official Google, Microsoft or OpenAI product.

For questions, use the information repository's public issue page. Do not include email content, credentials or other private information in an issue.
